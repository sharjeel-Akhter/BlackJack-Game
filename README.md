# ♠️ BlackJack Game

A simple and interactive BlackJack game built with HTML, CSS, and JavaScript. Test your luck and strategy by drawing cards and trying to reach a total of **21** without going over.

## 🚀 Live Demo

🌐 https://sharjeel-akhter.github.io/BlackJack-Game/

## 📌 Features

* Start a new BlackJack game instantly
* Draw random cards
* Real-time score calculation
* Win by reaching exactly 21
* Lose if your score exceeds 21
* Restart the game anytime
* Responsive and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 🎮 Game Rules

1. Click **Start Game** to receive two random cards.
2. Reach a total of exactly **21** to win.
3. Click **New Card** to draw an additional card.
4. If your total exceeds **21**, you lose the game.
5. After winning or losing, click **New Game** to start a fresh round.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/sharjeel-Akhter/BlackJack-Game.git
```

Navigate to the project folder:

```bash
cd BlackJack-Game
```

Open `index.html` in your browser.
